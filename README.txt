# Projeto SKZ — Recriação inspirada na tela da Crunchyroll

## Como abrir
1. Extraia a pasta `skz` na Área de Trabalho.
2. Entre na pasta `skz`.
3. Dê dois cliques em `index.html` para abrir no navegador.

Não precisa instalar nada para testar a versão frontend.

## Funções incluídas
- Layout responsivo inspirado na página de animes da imagem.
- Prateleiras horizontais com botões de navegação.
- Pesquisa por nome original, nome em português e gênero.
- Filtro por categoria.
- Janela de detalhes ao clicar em um anime.
- Botão para pesquisar o trailer no YouTube.
- Minha lista com salvamento no `localStorage` do navegador.
- Navegação demonstrativa e mensagens de interface.

## Observações
Este é um projeto de estudo, não o site oficial da Crunchyroll. Não inclui login real, assinatura, reprodução de episódios ou catálogo oficial. Os pôsteres e a imagem de destaque são carregados de URLs externas, então é necessária conexão com a internet para que apareçam. A disponibilidade dos links externos pode mudar.
